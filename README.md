# ApexPlanet Task 4 — Online Bookstore
PHP + MySQL starter project with authentication, admin book CRUD, search, category filtering, and pagination.

## Run locally
1. Extract this folder into `C:\xampp\htdocs\ApexPlanet_Task4_OnlineBookstore`.
2. Start Apache and MySQL in XAMPP.
3. Import `database.sql` using phpMyAdmin.
4. Check database settings in `config.php` (default XAMPP: root, blank password).
5. Open `http://localhost/ApexPlanet_Task4_OnlineBookstore/`.

## Admin account
Register through the website, then in phpMyAdmin open `apexplanet_bookstore` → `users` and change that account's `role` from `user` to `admin`. Log in again.

This is a learning starter. Test locally before recording your demo video.
